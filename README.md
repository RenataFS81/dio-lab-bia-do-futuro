# 🤖  💰 ReEduca Finanças — Agente Financeiro Inteligente com IA Generativa

## O ReEduca Finanças é um agente de inteligência artificial consultivo, proativo e educacional, desenvolvido em Python com **Streamlit** e integrado aos modelos de linguagem da Google Gemini API.

O projeto foi criado para transformar o atendimento financeiro reativo em uma consultoria personalizada. Ele analisa o histórico de transações e o perfil do cliente para organizar orçamentos, diagnosticar gastos e recomendar investimentos seguros de forma clara e acessível.
